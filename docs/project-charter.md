# Learning charter

## Objective

Develop practical familiarity with TypeScript syntax, strict typing, common utility concepts, and selected software design patterns through small focused examples.

## Scope represented today

- Type basics, inference, arrays, tuples, enums, functions, nullability, aliases, and control flow.
- Course-style coding challenges.
- Standalone examples of observer, factory, proxy, callback, and dependency-injection patterns.
- Strict compiler configuration for the source tree.

## Not in scope

- A web application, service, CLI product, reusable NPM package, or public API.
- Stable module APIs, semantic versioning, package publishing, or consumer support.
- Automated tests, CI, benchmark evidence, or deployment.

## Ownership and decision gate

This is a personal learning reference. It can support a skills narrative alongside stronger application repositories, but should not be presented as a production software product.

## Criteria for a future showcase project

1. Define one focused product or library objective.
2. Add package metadata, clear scripts, and an explicit entry point.
3. Add automated tests and CI checks.
4. Document usage, APIs, compatibility, and release policy.
5. Demonstrate a real integration or user outcome beyond isolated examples.
